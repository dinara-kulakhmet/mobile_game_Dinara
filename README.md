# Juicy Journey

Juicy Journey is a small 2D mobile platformer that I made in Unity. I wanted the game to feel cozy and sweet, so everything is bright and colorful, and the hero just goes on a fruit trip through a sunny world.

## What you do in the game

There are 3 levels. In each one you run and jump, collect watermelons and kiwis to get points, and stay away from the spiked bombs, because every hit takes one of your 3 lives. On the last level there is a boss. He shoots fireballs at you in a fan and also makes fire rain from above. When his health gets low he attacks faster, so the end of the fight gets a bit stressful. If you beat him, you see the "You Win" screen.

## Controls

The game is made for phones, so everything is on the screen:

- joystick in the bottom left: move
- JUMP and FIRE buttons in the bottom right: jump and shoot
- pause button in the top right: opens the pause menu (Resume, Restart, Menu)

## Screens

Main menu (Play, Levels, Quit), the HUD during the game (points, lives, pause button, controls, and the boss health bar on the last level), the pause screen, Game Over and You Win.

I set up the UI to scale with the screen size and to stay inside the safe area, so it should look fine on a normal 16:9 phone, on a phone with a notch, and on a 4:3 tablet.
